# Общий принцип следующих визуальных редакторов

Использовать `editor_documents.render_editor` и `grid_editor.html`.

- Непрерывное рисование одиночными кликами; Esc завершает режим.
- Общие узлы пересечений, дополнительные узлы изгиба, Ctrl+Z.
- Скачать JSON или ZIP без имени, галочек, диалогов и блокировки сохранения.
- Не менять исходные координаты при простом открытии и сохранении.
- Сохранение не подтверждает точность. Новые/исправленные данные имеют
  `human_verified: false`; прежний подтверждённый статус сохраняется только
  при отсутствии правок. Оценка подтверждения отделена от экспорта.
- JSON хранит совместимые `horizontal_polylines`/`vertical_polylines`,
  общие `graph_nodes` и ссылки семейств линий. Непригодная для вычислений
  разметка всё равно может быть сохранена и исправлена позже.

Исторические шаблоны `review_template.html` и `linked_review_template.html`
оставлены для воспроизведения прежних отчётов, не для новых интерфейсов.
