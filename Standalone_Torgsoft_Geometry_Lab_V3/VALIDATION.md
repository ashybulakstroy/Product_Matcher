# Проверка независимого ZIP до передачи

**Подтверждено в среде сборки пакета:**

- Исходники написаны внутри V3; старые trial-папки, результаты и модели не используются.
- `python -m pytest -q tests`: **13 тестов пройдены** (см. повторный запуск перед упаковкой).
- Включены независимые демо-фотографии (синтетика), которые не нужны для основных испытаний.
- `benchmark` сам создаёт `summary.html`, `run.json`, per-case JSON, выпрямленные изображения,
  наложение синей сетки и визуализацию обратного переноса.
- Без файлов Baseline в основной программе метод получает статус `NOT_AVAILABLE`.
- Без человеческой разметки GT отчёт даёт `GT_MISSING`.
- Переключение на настоящий `web_outputs` осуществляется параметром `--source` или
  расположением V3 в корне основного репозитория.

**Не подтверждено:**

- Реальная точность выпрямления волн/складок на новых фото чеков пользователя.
- Процент совпадения сетки с физическими линиями на реальном наборе.
- Работа в установленной Windows-среде пользователя до запуска там.

Тесты на синтетических фотографиях демонстрируют исполняемость, но НЕ являются
доказательством качества на реальных чековых фотографиях. Задача Codex — измерить
это с независимым GT и не скрывать отказы или нерезультативные фото.
