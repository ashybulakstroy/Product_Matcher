Редактор печатной сетки

В режиме рисования каждый клик создаёт линию, режим остаётся включён. Esc — закончить, Ctrl+Z — отменить. Правой кнопкой можно обвести рабочую область таблицы. Узлы пересечений общие для двух линий. В режиме редактирования двойной клик по линии добавляет узел изгиба. Shift + перетаскивание узла — вся горизонталь, Alt — вертикаль. Скачивание ничего не подтверждает автоматически.
