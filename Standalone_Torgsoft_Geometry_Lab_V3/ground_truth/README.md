Папка предназначена только для НОВЫХ ручных эталонов.
Имена файлов: <SHA256 исходных байтов upload.bin, иначе original.png>.json
Формат: {"sha256":"...", "vertical_polylines":[[[x,y],...], ...], "horizontal_polylines":[[[x,y],...], ...]}
Точки задаются в пикселях ORIGINAL.PNG после ориентации, а не в исходном JPEG до поворота.
Вертикальные линии перечисляются слева направо (обычно 5).
Горизонтальные — сверху вниз; каждая линия содержит >=2 точек.
НЕ копируйте сюда старые результаты Trial и НЕ генерируйте GT из предсказаний.
Нет GT -> GT_MISSING, не «точность = 0».
